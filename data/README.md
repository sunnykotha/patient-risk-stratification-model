# Synthetic readmission dataset

`synthetic_readmissions.csv` is generated by
`scripts/generate_synthetic_data.py` using a fixed random seed.

- Contains 240 simulated patient records.
- Includes numeric risk features and a binary 30-day readmission label.
- Includes some intentionally missing laboratory and vital-trend values.
- The label is simulated from a risk formula; it is not derived from real patient outcomes.

This dataset exists only for software development, automated testing, and demonstration.
It is not clinical evidence and must not be used to make patient-care decisions.
